# 🚀 DevStack
A modern technology stack builder built with React and TypeScript.

## 🛠️ Technologies Used
- HTML
- CSS
- TypeScript
- React
- TailWind CSS
  
## ✨ Features
- You can add technologies in 'Your Stack'
- You can remove technologies from 'Your Stack'
- You can remove all technologies from 'Your Stack'
